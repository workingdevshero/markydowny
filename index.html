Live reload and Follow

Keep a document open while it changes. When the file changes on disk, Markydowny re-renders it, keeps your place and highlights what changed. Turn on Follow and the latest change stays in view.

In the Mac app, every open document reloads. On the web, a file you choose or drop reloads in Chrome, Edge and other Chromium browsers; Safari and Firefox read it once.

Live reload & Follow

An editor that looks like the page

Press Edit to change the document. Rich mode styles the markdown as you type, and a toolbar and shortcuts take care of the syntax. Prefer the source? Switch to Markdown, or see both side by side.

Saving writes the file in place in the Mac app, and on the web in Chromium browsers for a file you chose or dropped. Other browsers download a copy.

Editor

Tabs on your Mac

Double-click a .md file and it opens in its own native tab. Open a file that's already open and its tab comes forward. Drop a folder to open its files as tabs, or watch it and see whichever file changes.

Tabs & windows

Watch Claude Code edit

Open the document, ask Claude Code to change it, and watch each edit land, highlighted as it goes.

On a Mac, a Claude Code hook opens each markdown file Claude edits. Later edits to that file reload in the background, without pulling focus from your terminal.

Watching Claude Code

Your files stay yours

Nothing is uploaded. The page reads your files in your browser, with no account and no analytics, and once it has loaded it needs no network.
