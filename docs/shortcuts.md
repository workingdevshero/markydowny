# Keyboard shortcuts

| Action | Mac | Windows and Linux |
| --- | --- | --- |
| Edit the markdown, or go back to the rendered view (Edit / Done) | <kbd>⌘E</kbd> | <kbd>Ctrl+E</kbd> |
| Save while editing | <kbd>⌘S</kbd> | <kbd>Ctrl+S</kbd> |
| Find and replace while editing | <kbd>⌘F</kbd> | <kbd>Ctrl+F</kbd> |
| Choose a file from the drop zone | <kbd>Enter</kbd> or <kbd>Space</kbd> | <kbd>Enter</kbd> or <kbd>Space</kbd> |
| Close an enlarged image | <kbd>Esc</kbd> | <kbd>Esc</kbd> |
| New file (app) | <kbd>⌘N</kbd> | <kbd>Ctrl+N</kbd> |
| Open a file (app) | <kbd>⌘O</kbd> | <kbd>Ctrl+O</kbd> |
| New tab (Mac app) | <kbd>⌘T</kbd> | |
| Next tab (Mac app) | <kbd>⌃Tab</kbd> or <kbd>⌘⇧]</kbd> | |
| Previous tab (Mac app) | <kbd>⌃⇧Tab</kbd> or <kbd>⌘⇧[</kbd> | |
| Close the tab or window (Mac app) | <kbd>⌘W</kbd> | |
| Quit (Mac app) | <kbd>⌘Q</kbd> | |

Scrolling with the arrow keys, <kbd>Page Up</kbd>, <kbd>Page Down</kbd>, <kbd>Home</kbd>, <kbd>End</kbd> or <kbd>Space</kbd> pauses [Follow](live-reload.md#follow-and-resume), like scrolling with the mouse.

The Windows and Linux column covers the website in any browser and the Linux and Windows builds of the app, which have no tabs.

In the editor, the usual text editing keys work: undo and redo, select all, and moving by word or line.
