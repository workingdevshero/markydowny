Keyboard shortcuts

Action Mac Windows and Linux
Edit the markdown, or go back to the rendered view (Edit / Done) ⌘E Ctrl+E
Save while editing ⌘S Ctrl+S
Save As, to a file you pick ⇧⌘S Ctrl+Shift+S
Find and replace while editing ⌘F Ctrl+F
Choose a file from the drop zone Enter or Space Enter or Space
Close an enlarged image Esc Esc
New file (app) ⌘N Ctrl+N
Open a file (app) ⌘O Ctrl+O
New tab (Mac app) ⌘T
Next tab (Mac app) ⌃Tab or ⌘⇧]
Previous tab (Mac app) ⌃⇧Tab or ⌘⇧[
Close the tab or window (Mac app) ⌘W
Quit (Mac app) ⌘Q

Scrolling with the arrow keys, Page Up, Page Down, Home, End or Space pauses Follow, like scrolling with the mouse.

The Windows and Linux column covers the website in any browser and the Linux and Windows builds of the app, which have no tabs.

In the editor, the usual text editing keys work: undo and redo, select all, and moving by word or line.
